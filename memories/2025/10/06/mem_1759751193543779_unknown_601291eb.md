# API Design Pattern Discovery

Found an elegant pattern for handling authentication in microservices:
- Use JWT tokens with short expiration (15 min)
- Refresh tokens stored in httpOnly cookies
- Token rotation on each API call
- Invalidation list in Redis for immediate logout

This solves the stateless auth problem while maintaining security.
Key insight: Balance between security and user experience.
