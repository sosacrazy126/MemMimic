# Team Collaboration Insight

During code review today, realized that async communication works better than meetings for:
- Architecture discussions (allows time to think)
- Code reviews (written feedback is clearer)
- Technical decisions (documentation as byproduct)

Meetings still valuable for:
- Brainstorming new features
- Resolving conflicts
- Building team rapport

The key is matching communication method to purpose.
