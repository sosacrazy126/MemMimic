# Code Review Feedback Pattern

Discovered effective code review feedback structure:

1. Start with what works well
2. Ask questions instead of making demands
3. Provide context for suggestions
4. Distinguish between blocking vs nice-to-have
5. Offer to pair program on complex changes

This approach reduces defensiveness and improves learning.
Remember: Code review is teaching, not gatekeeping.
